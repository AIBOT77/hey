# 🚀 Smart Task Manager - Quick Overview

## What You've Built
A **winning hackathon project** that combines AI-powered task management with real-time collaboration.

## 🎯 Key Features
- **AI Task Categorization** - Automatically organizes tasks
- **Smart Priority Suggestions** - Based on content and due dates  
- **Real-time Collaboration** - WebSocket-powered live updates
- **Beautiful Modern UI** - Responsive design with animations
- **Full-stack Application** - React + FastAPI + SQLite

## 🚀 How to Run

### Quick Start (Docker)
```bash
./start.sh
```

### Manual Start
```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend  
cd frontend
npm install
npm start
```

## 📱 Access Points
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs
